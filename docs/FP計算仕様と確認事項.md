更新日：2026年9月24日

## お客様への説明で最初に伝えること

「この試算は、今確認できる収入と、ご希望の暮らしに必要な支出から、将来のお金の残り方を確認するものです。借入できる上限と、安心して暮らせる予算は異なります。条件が変わった場合も一緒に確認し、無理のない計画を考えましょう。」

将来の金利・収入・物価・制度・健康状態は確定しないため、「絶対に大丈夫」「必ずこの金額が残る」とは説明しないでください。

## 直した主な問題

| 項目 | 今回の扱い |

| 最終残高 | 画面・提案書・年次表を同じ計算結果に統一。30・40・50・60年後を同時表示 |

## 最後に残るお金の計算

**現在の世帯貯蓄 − 購入時の現金支出 ＋ 累計収入 − 累計支出 ＝ 手元資金**

- 購入時の現金支出：住宅・別途設備の総費用と実借入額の差。借入が費用を上回る場合、超過分を手元資金に加えず警告します。
- 収入：給与・賞与の手取り、年金、退職金、確認済み控除、保険満期受取、売電。
- 支出：住宅ローン・繰上返済、他ローン、生活費・保険、節電後の光熱費、教育・仕送り、固定資産税等、修繕・設備更新、旅行・車等。
- 手元資金は現預金の概算です。自宅の売却価値や未受取の保険積立は含みません。残る借入は別表示です。
- マイナスは資金不足額。追加借入や、その不足に対する利息は自動で加えません。
- 初年度から60年目末まで計算します。表示年齢は年末時点。暦年途中の税・初年度返済・支払日の厳密な日割りは扱いません。
- 内部で万円に丸めず、表示時だけ丸めます。表に見える数字の合計に端数差が出ることがあります。

## 月々の暮らしと、大きな支出

「家計・教育費」で現役期と退職後の生活費を入力します。退職後への切替は世帯主の定年が基準です。

旅行や車は「予定支出」に1回の費用、最初の年、間隔、最後の年を設定します。1回限りも設定できます。例：毎年20万円の旅行、8年ごと250万円の車。車の維持費と買い替え費、娯楽費と旅行費は二重計上しないよう確認してください。

月額予算は初年度の給与・賞与等を12で割った平均です。賞与のない月の収支とは異なります。修繕・旅行・車の積立目安は、選択期間の予定総額を月割りします。**年次残高では積立分を再び引かず、支出が発生する年だけ費用を引きます。**

年末残高がプラスでも、車購入直前など年内の資金不足は別途確認が必要です。生活防衛資金の月数は基本情報で設定できます。これは確保する目標で、追加の支出にはしません。

## 収入・教育費の前提

- 給与は賞与を除く額面年収。賞与は別入力。手取り率は各人で変更でき、初期値80%は仮定です。
- 自動給与は50歳まで設定率で昇給、51～54歳横ばい、55～59歳は年3%減、60歳は35%減、以降年1%減の仮定。勤務先に合わなければ手動へ変更してください。
- 手動給与は30・35・40・45・50・55・60・65歳の設定値を5歳区分で使います。30歳未満は最初、65歳以降は最後の値です。
- 年金の自動値は現在年収・22歳就業等を使った粗い推計の90%。実際の加入歴・税社会保険・在職年金は正確に再現しません。ねんきん定期便等から手取り見込月額を入力してください。
- 産休・育休給付は概算率で、受給資格・上限や追加給付は未反映です。勤務先の確認が必要です。
- 子は最大3人。小学校は公立の想定。私立小学校や個別進路は年間教育費・予定支出で調整してください。
- 幼稚園～高校の初期年間費用は文部科学省の訂正済み調査。塾・習い事等が含まれるため、家計の娯楽費などとの重複を確認してください。
- 大学・専門学校の初期値は従来の仮予算で、最新の学校別見積ではありません。学費・入学金・教材・下宿・仕送りを確認して編集してください。
- 0～2歳の保育料、介護・災害費などは自動計上しません。必要額は予定支出へ追加してください。
- 児童手当・補助金・運用益・相続・売却益は自動計上しません。

## 金利・税金・保険

- 審査金利は最大借入額の逆算用です。実際の返済は「ローン計画」の採用金利を使います。
- 元利均等、最大60年、3段階の金利。段階の終了は「借入から何年後か」です。全期間固定は第1期を全期間に設定してください。
- 変動金利の5年ルール・125%ルール、団信上乗せ、金融機関固有の手数料・返済日・端数処理は未反映。銀行の返済予定表と照合してください。
- ペアローンは共通条件で合算します。夫婦で金利・期間が異なる契約は個別計算が必要です。
- 住宅ローン控除は2026～2030年の対応区分を概算。税額・床面積・持分・居住等の全要件を判定する機能ではありません。試算開始年と入居年が異なる場合や未対応の経過措置は計上しません。
- 控除上限は給与収入が減ると比例縮小し、給与0の年は0とする保守的な扱いです。年金所得等で使える控除を再現するものではありません。
- 固定資産税は出雲市1.5%、都市計画税は対象区域に限り0.075%。評価額は手入力優先。自動値は延床面積・土地面積（坪）×評価単価を万円単位で丸めた仮評価額です。建物の面積は1階の建築面積ではなく、各階の床面積の合計です。
- 新規入力の評価単価は建物38万円/坪・土地11万円/坪という仮定で、市の公表単価でも工事費の坪単価でもありません。物件の確認額に合わせて変更してください。建物代・土地代は購入費用用で、評価単価とは連動しません。
- 旧保存データは以前の自動評価額（建物代×45%・土地代×70%、価格0なら面積×従来単価）を保存面積で割り、単価を引き継ぎます。読み込み時の年税額は維持します。面積0の旧データのみ、以前の評価額を手動値として保持します。単価は画面では小数4桁、内部では元の精度で保持します。
- 手動評価額は面積・単価を変えても固定です。面積変更による軽減対象部分の按分は反映します。自動計算に戻すと、現在の面積×単価を使います。
- 建物の新築軽減は住宅部分120㎡相当まで、一般3年・認定長期優良5年。土地は住宅用地特例を200㎡で按分。建物の経年減価・評価替えは未反映です。
- 貯蓄型保険は「満期年末まで毎月払い、その年末に受取」の想定です。払込終了と満期が異なる保険、保険税務は個別確認が必要です。

## 太陽光・蓄電池

使用量は **kWh/月**、設備容量は **kW**、蓄電容量は **kWh** です。Wはその瞬間の消費電力で、月の電気使用量とは異なります。

| 人数 | 月間使用量の目安 |
| --- | ---: |
| 1人 | 約201kWh |
| 2人 | 約331kWh |
| 3人 | 約428kWh |
| 4人 | 約477kWh |
| 5人 | 約537kWh |
| 6人以上 | 約748kWh |

環境省の令和5年度・確報図1-62の丸め済み年間GJ表示値を、1kWh=0.0036GJとして12分割した概数です。全国の戸建て・集合住宅・ガス併用等を含み、**オール電化住宅専用の平均ではありません**。実際の電気明細を優先してください。

- 発電量は手入力の年間値・月別値を優先。自動値は1kW当たり年1,000kWhを基本に、パワコン容量比と月別係数で概算します。屋根方位・影・積雪は自動判定しません。
- 昼の直接消費、夜に使える蓄電量、充放電ロス、売電を分けます。月平均モデルで、時間別の天候や電力ピークは再現しません。
- 買電は昼夜単価と基本料金、または手入力の電気代。燃料費調整・再エネ賦課金等は入力単価・料金に含めてください。
- 退職後も使用量・昼夜比率は同じ想定です。退職後の光熱費は別入力できますが、時間別需要の変化は未反映です。
- 初期費用の資金手当、パワコン・蓄電池交換、点検、パネル更新費、発電低下率を設定できます。
- 2026年度の住宅用10kW未満FITの目安は当初4年24円、5～10年目8.3円。既存データの単価は勝手に変更せず、適用ボタンで切り替えます。FIT後8円は仮定です。
- 設備比較の回収グラフは初期費用・更新費と節電・売電を比較し、借入利息は設備単体の比較から除きます。家計では実際のローンに含めます。

## 現役中・退職後の支出

全60年の基本条件の年次収支を、各年の開始時点の世帯主年齢が退職年齢未満かどうかで分けます。各期間の支出総額÷対象年数÷12が月平均です。住宅ローン・繰上返済、生活費・掛捨保険、他ローン、貯蓄型保険、光熱費、税、教育、修繕、予定支出を分けて表示し、二重計上しません。

この表は30・40・50年表示中も60年分を使うため、退職が選択年数より先の場合も退職後を確認できます。対象年齢・年数を列見出しに明記します。既に退職済み、または60年以内に退職しない場合は、該当しない列を「対象期間なし」とし、ゼロ円の生活費を仮定しません。

家計欄の入力は現在価格の月額ですが、この表は設定した将来の物価上昇や年単位の支出を含む期間平均です。毎月の引落額や初年度の月額予算とは異なります。平均額を年次残高から追加で差し引くことはありません。配偶者の就業状況にかかわらず、生活費の切替基準は世帯主の退職時点です。

## 以前の比較設定について

以前の「比較設定」は金利上乗せ・給与減少・支出増加を仮定した別の試算を作る機能でした。9月24日から総合まとめ・提案書には基本条件だけを表示し、比較設定・比較結果・赤い破線を除外しました。過去の保存データ内の比較設定や確認チェックは互換性のため保持しますが、現在の残高・支出表・提案書の表示には使用しません。基本条件の計算式と結果は変更していません。

## 保存とお客様への提示

1. 明細・見積に合わせて入力し、旅行・車・進路も確認します。
2. 総合まとめの月平均余力、30～60年後の残高、最初の不足年を確認します。
3. 現役中・退職後の支出内訳と生活防衛資金を確認します。
4. 入力した見積・収入・生活費と、試算に採用した条件を照合します。画面の確認チェック欄はありません。
5. 「提案書・PDF」で印刷画面へ進み、PDFとして保存します。「提案書を保存」は単独で開けるHTMLです。
6. 再編集用に「入力データ保存」のJSONも残します。年次明細はCSVで保存できます。

提案書は通常8区分（総括・初年度月額予算・現役中と退職後の支出・採用条件・予定支出と計算注記・年次表3区分）です。支出名や注意事項が多い場合、印刷のページ数は増えます。印刷プレビューで最終確認してください。

公開版の通常保存は使用ブラウザー内です。他PCへの自動同期ではありません。JSON・HTML・CSV・PDFにはお客様の家計情報が入るため、会社の保管ルールで管理してください。クラウド連携を別途設定した環境では保存先・アクセス権の確認が必要です。今回、既存顧客データを公開サイトへアップロードしていません。
